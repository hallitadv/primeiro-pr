# primeiro-pr

Repositório de prática para o meu primeiro Pull Request no GitHub.

## O que é um Pull Request?

Um Pull Request (PR) é uma forma de propor mudanças em um repositório. Em vez de alterar o código diretamente, você cria uma cópia (branch), faz as alterações, e então abre um PR para que as mudanças sejam revisadas antes de serem incorporadas ao projeto principal.

## Como foi feito este PR

1. Clonei o repositório localmente
2. Criei uma branch separada (`melhoria/readme`)
3. Melhorei este arquivo README
4. Abri um Pull Request com a mudança
